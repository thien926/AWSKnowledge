## AWS SDK là gì?

1. **AWS Software Development Kit (AWS SDK)**  
   - Dịch: Bộ phát triển phần mềm của AWS (AWS SDK)  
   - Giải thích: Tập hợp thư viện và công cụ giúp lập trình viên gọi API AWS dễ dàng.

2. **Language-specific APIs (set of libraries)**  
   - Dịch: API chuyên biệt cho từng ngôn ngữ (tập hợp thư viện)  
   - Giải thích: Mỗi SDK được đóng gói dưới dạng thư viện tương thích với ngôn ngữ lập trình nhất định.

3. **Enables you to access and manage AWS services programmatically**  
   - Dịch: Cho phép bạn truy cập và quản lý dịch vụ AWS theo lập trình  
   - Giải thích: Thay vì thao tác trên Console, bạn có thể viết code gọi thẳng API để tự động hóa.

4. **Embedded within your application**  
   - Dịch: Nhúng trực tiếp vào ứng dụng của bạn  
   - Giải thích: SDK được tích hợp vào mã nguồn, chạy song song với logic nghiệp vụ.

5. **Supports:**  
   - **SDKs (JavaScript, Python, PHP, .NET, Ruby, Java, Go, Node.js, C++)**  
     - Giải thích: Hỗ trợ hầu hết ngôn ngữ phổ biến trên server và desktop.  
   - **Mobile SDKs (Android, iOS, …)**  
     - Giải thích: Thư viện dành riêng cho ứng dụng di động, tương tác với AWS từ điện thoại.  
   - **IoT Device SDKs (Embedded C, Arduino, …)**  
     - Giải thích: SDK tối ưu cho thiết bị nhúng, cảm biến IoT kết nối trực tiếp đến AWS.

6. **Example: AWS CLI is built on AWS SDK for Python**  
   - Dịch: Ví dụ: AWS CLI được xây dựng trên AWS SDK cho Python  
   - Giải thích: Công cụ dòng lệnh AWS CLI thực chất sử dụng thư viện `boto3` (AWS SDK for Python) để gọi API.

---

**Tóm lại:**  
- AWS SDK giúp bạn lập trình giao tiếp với AWS dễ dàng và nhất quán trên nhiều ngôn ngữ.  
- Phù hợp cho phát triển ứng dụng web, di động, IoT hoặc tự động hóa hạ tầng.
